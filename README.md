# Sentinelalog
Sistema em Python, no terminal, que registra acessos a um laboratório de 30 máquinas, classifica acessos suspeitos e mantém um log de auditória.
Para a construção do sistemas utilizamos estruturas como funções, estruturas de repetição, condicionais e tratamentos de erros, para cada tarefa do CRUD ( Create, Read, Update e Delete) utilizamos uma função e dentro das funções as estruturas acima mensionadas.
